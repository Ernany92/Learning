# Sistema de Cadastro Simples em Python

## 📌 Descrição
Este projeto é um sistema simples desenvolvido em Python com o objetivo de praticar os principais conceitos aprendidos em aula, como estruturas de repetição, estruturas condicionais e uso de listas.

O programa permite cadastrar pessoas, listar os cadastros e remover registros através de um menu interativo no terminal.

---

## 🧠 Conteúdos Trabalhados
- Entrada e saída de dados (`input` e `print`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Estrutura de repetição (`while True`)
- Listas em Python
- Manipulação de listas (`append`, `remove`)
- Laço de repetição (`for`)
- Validação de dados
- Menu interativo

---

## ⚙️ Funcionalidades
- ✅ Cadastrar nome e idade
- ✅ Listar pessoas cadastradas
- ✅ Remover pessoa pelo nome
- ✅ Encerrar o programa pelo menu
